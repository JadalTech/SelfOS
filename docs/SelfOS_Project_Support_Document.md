# SelfOS -- AI-Powered Personal Health & Self-Improvement Platform

Version: 1.0

## Purpose

Build a production-quality mobile application that helps users manage
personal improvement in one place.

Primary modules: - Haircare - Skincare - Nutrition - Protein planner -
Water tracker - Gym - Sleep - Progress photos - AI coach - Habit
analytics

This is intended to be a real portfolio project suitable for Full Stack
/ Frontend / React Native interviews.

------------------------------------------------------------------------

# Vision

People struggle because their self-improvement routine is spread across
notes, reminders, calendars and memory.

SelfOS becomes one intelligent operating system for personal growth.
